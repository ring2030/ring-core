# ROP Launch Plan — ring goes open

**Status:** living document  
**Audience:** steering committee, mentors, Technovation liaison  
**Related:** [`docs/spec/ROP-1.0.md`](./ROP-1.0.md), [`governance/GOVERNANCE.md`](../governance/GOVERNANCE.md)

---

## Phase 1 (month 1)

| Deliverable | Owner | Exit criterion |
|-------------|-------|------------------|
| Spec draft **ROP-1.0** on `main` | Tech lead + mentors | Public markdown + `/api/spec/rop-1-0` serves same bytes |
| `@ring-open/core` **1.0.0-alpha.1** on npm | Adult mentor | `npm publish` + tarball smoke test |
| Recipes **`ja-jp-japan`** & **`en-us-usa`** | ring team | `locale.json` + `cultural-notes.md` reviewed by native speaker |
| GitHub org **`ring-open`** skeleton | Mentors | Org README, team permissions, 2FA enforced |
| Academy first **3 lessons** (`00`–`02`) | ring team + teacher | Pilot feedback notes in `academy/00-welcome/pilot-notes.md` (optional) |
| Landing **`/open-protocol`** | ring team | Linked from README |

## Phase 2 (month 3)

- Open calls for **es / hi / sw** recipe maintainers (public Discussions only).  
- Academy **full course** (`03`–`capstone`).  
- **ROP 1.0** (non-draft) after at least **one external pilot** implementation (school club or hospital innovation cell).  
- First **Conformance Statement** published by external team.

## Phase 3 (year 1)

- **5+** independent implementations tracked in `docs/ADOPTERS.md` (to be created when first adopter appears).  
- Academic citation using **PHIL** aggregates (see `/insights`).  
- Conference proposals (ITU, WHO digital health side-events, UN Women STEM).

## Launch channels (non-exhaustive)

- Hacker News, `r/programming`, Fediverse, LinkedIn — **always** link spec + CoC.  
- Technovation official Slack/forum — mentor posts, minors comment in-thread only.  
- Education press — pitch emphasises **pedagogy + ethics**, not medical claims.

## Success metrics (aspirational)

| Metric | 6 mo | 12 mo |
|--------|------|-------|
| GitHub stars | 1 000+ | 3 000+ |
| Recipe locales | 4 | 10+ |
| Academy completions (self-reported) | 30 | 100 |
| External implementations | 1 | 5+ |
| Academic citations of PHIL | 0 | 1+ |

## Messaging guardrails

- Never claim **medical device** or **diagnostic** status.  
- Never route **adult ↔ minor** communication to private DMs as part of project governance.  
- Credit **youth authors** by first name + age band when they consent; otherwise team credit.
