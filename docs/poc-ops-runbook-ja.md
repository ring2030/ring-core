# PoC運用ランブック（高校生向け）

## 1. これは何のメモ？

「トラブルが起きたとき、どこを見ればいいか」をまとめた運用メモです。

## 2. よくあるトラブルと対処

### ログインできない

- 入力ミス確認（`1 / 1`）
- `.data/nurse-accounts.json` の内容確認
- 直前でアカウントを disable していないか確認

### 画面が空になる

- `/settings` で `Current hospital` を確認
- `Switch hospital` を押して戻す
- その病院コレクションにデータがあるか確認

### 監査ログが出ない

- まず操作を1回行う（ログイン、切替、招待作成など）
- `/settings` の監査ログ一覧を再表示
- `Download CSV` で出力可否を確認

## 3. デモ前の最終確認

- ログインOK
- 病院切替OK
- 所属追加OK
- CSV出力OK
- 既存画面表示OK

## 4. 禁止事項（PoCでも守る）

- 他病院のデータを混ぜて説明しない
- 共有IDを増やしすぎない
- 監査ログを消した状態でデモしない
