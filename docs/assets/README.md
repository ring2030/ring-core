# Contest assets

This folder holds **screenshot placeholders** (SVG) linked from the root `README.md`.

To swap in real captures for a submission:

1. Export PNGs (e.g. 1200×675 or your preferred aspect ratio) from:
   - `/` — patient gaze home  
   - `/dashboard/nurse` — nurse queue  
   - `/dashboard/family` — family view  
2. Name them e.g. `patient-home.png`, `nurse-dashboard.png`, `family-dashboard.png` in this directory.  
3. In the root `README.md`, change the image paths from `*.svg` to `*.png` (or keep SVG and delete the PNGs if you prefer vector placeholders).

Optional: add a `demo.mp4` and link it from the main README.
