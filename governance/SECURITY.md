# Security policy

## Supported versions

| Component | Supported |
|-----------|-----------|
| `ring-core` (this app) | `main` branch only |
| `@ring-open/core` | Latest published semver |

## Reporting a vulnerability

**Please do not** file public GitHub issues for undisclosed security vulnerabilities.

Email the maintainer team at: **security@example.org** (replace with the adult mentor inbox once published).

Include:

- Description and impact  
- Steps to reproduce  
- Suggested fix (optional)

We aim to acknowledge within **72 hours** and coordinate disclosure.

## Scope notes

- ROP is **not** a regulated medical device; reports should focus on **software security** (auth, data exposure, supply chain) and **child-safety** process failures.

## Safe harbour

We support good-faith security research that follows this policy.
