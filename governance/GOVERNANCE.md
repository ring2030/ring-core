# Governance — ring Open Protocol (ROP)

## Roles

- **Steering committee:** 3–5 trusted adults (mentors + technical lead) — budget, legal, trademark, release keys.  
- **Core maintainers:** adults + exceptional youth alumni — day-to-day merges after review.  
- **Contributors:** anyone following the Code of Conduct and RFC process.

## Decision making

- **Routine changes** (bugfixes, docs, tests): one maintainer approval.  
- **Normative spec changes:** RFC + steering committee lazy consensus within 14 days.  
- **Trademark / press / partnership:** steering committee majority.

## Youth participation

Contributions from ages 11–18 are celebrated. **Mentors** provide review and escalation paths. **No youth-only private maintainer channels** for production access — two-adult rule for secrets (npm, Vercel, Firebase).

## Conflicts of interest

Mentors declare employer relationships in healthcare or eye-tracking vendors when relevant to a technical discussion.
