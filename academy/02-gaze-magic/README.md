# Lesson 02 — Gaze magic (TensorFlow.js)

**Time:** 45–60 minutes  
**Goal:** print “eye detected” when a face is on camera.

## Vocabulary

- **Tensor:** a big multi-dimensional array of numbers.  
- **Model:** a file that learned patterns from many photos.  
- **FPS:** frames per second — your loop should stay smooth.

## Minimal path (mentor-assisted)

1. Start from the Vite app in lesson 01.  
2. Follow TensorFlow.js face-detection quickstart:  
   [https://github.com/tensorflow/tfjs-models/tree/master/face-detection](https://github.com/tensorflow/tfjs-models/tree/master/face-detection)  
3. Draw nothing fancy yet — log bounding boxes.

## Privacy talk (mandatory)

Camera frames should stay **in the browser** for this lesson. Do **not** upload video to a random server.

## Homework story

> Show your camera preview to a family member. **What colour border** makes them feel calm instead of “hospital alarm”?

Write the answer — you will use it when picking UI colours for your recipe.
